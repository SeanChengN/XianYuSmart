# 搜索结果保留与商品参考数据

基线：`edcf3fe`。本轮不新增数据库表，不修改评分、排序和价格统计规则，不保存整理草稿或发布步骤。

## 使用方式

- 商机发掘的关键词/店铺搜索、全站比价分别保留最近一次成功搜索。按系统登录用户名、闲鱼账号和页面隔离。
- 切换页面、刷新页面和切换账号只恢复缓存。恢复前读取本系统账号列表，剔除不可访问账号；不会自动搜索、获取详情或导入货源。
- 缓存包含成功查询条件、结果、分页、获取时间和结果内已有的 SKU 快照；全站比价还包含价格筛选与排序。未提交的新关键词不替换上次成功搜索条件。
- 返回商机发掘时回到第一步，选择和预览为空，整理内容与发布参数重新填写。
- “清空搜索结果”仅清除当前页面、当前账号的结果。退出登录、登录失效和切换系统用户清除缓存。
- 数据存放在共享内存和 `sessionStorage`，不形成长期搜索历史。关闭浏览器会话后不保证保留。存储不可用时仍保留内存结果，并提示刷新可能丢失。
- 搜索失败保留上次成功结果及时间。旧查询、旧账号、离开页面后的迟到响应不更新结果。

## 商品标签的来源与边界

`soldCountText`、`wantCountText` 为兼容性新增的可空字符串，两个页面使用同一展示组件。

只读取商品卡片 `fishTags.r3.tagList[].data.content` 中明确的数量标签，覆盖当前搜索、旧搜索、`cardData` 及店铺卡片同类结构。保留“879人想要”“已售1.2万+”“0人想要”等原始精度。异常标签不猜测；缺失显示“已售：未提供”“想要：未提供”。

不读取标题、描述、卖家累计统计或埋点 `wantNum`。此前真实浏览器样本显示“879人想要”，埋点却为 0，二者不可替代。标签提取不额外请求详情。
