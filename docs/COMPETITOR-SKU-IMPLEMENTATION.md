# 竞品 SKU 实施与验收记录

本轮交付工作区代码及本机测试容器，不提交、推送或部署 NAS。自动页面回归使用合成 API；另已独立核验一个公开商品的 Chrome 响应和容器真实 SKU 采集。未发布商品、创建订单或调用 AI/图片生成服务。

## 已实现

- `POST /api/merchant/opportunities/detail` 接收 `xianyuAccountId`、字符串 `itemId`、布尔 `forceRefresh`。沿用运营操作权限，服务再次检查租户和账号归属。
- 全站比价、商机发掘、独立货源库与运营中心共用规格组件。搜索不补拉详情，查看规格或入库才采集；货源已保存快照可直接回看。
- 详情服务按租户、账号、商品缓存一小时，最多 512 个结果；合并相同商品的在途请求。同账号串行，请求完成后至少间隔三秒，刷新和详情令牌重试均受熔断检查约束。缓存与合并范围为单个应用进程。
- 导入、来源链接、仅商品 ID、选品入库及工作流采集均走竞品详情服务，不调用自有商品详情同步，不写自有 SKU/发货表。
- 快照写入 `SUPPLY.data_json.competitorSnapshot`，无数据库迁移。客户端提交的快照和来源标记会被过滤。货源编辑保留服务端快照，更换账号、商品 ID 或来源商品会清除旧快照。
- 更新失败保留之前的 SKU、采集时间，另存本次尝试时间、原因与过期标记。批次遇到验证或风控立即停止后续详情调用。
- 验证错误沿用任务失败状态，SQL 将 `max_attempts` 固定为已执行次数，并清空 `next_retry_time`；手动重试恢复通常的次数上限。Cookie 更新路径没有新增任务重排队逻辑，登录保活保持原流程。
- 搜索汇总使用整数分计算，标明搜索展示价与不同规格尚未对齐；显示两位小数。商机发布草稿价格、库存为空。货源转素材保留竞品快照，但价格与库存为零，需人工填写后才能发布；仍为单规格发布。

## 快照语义

`competitorSnapshot` 包含商品 ID、展示价、状态、来源、成功采集时间、本次尝试时间、`stale`、提示及原因。每个 SKU 包含字符串 ID、可空的 `priceCents`/`quantity`、原始 `rawPrice`、价格状态和完整规格属性（名称、值、字符串 ID、排序字段）。缺失值不补默认库存或价格。

| 状态 | 含义 |
| --- | --- |
| AVAILABLE | 已解析规格价格 |
| PARTIAL | 部分行、规格属性或价格不可用 |
| NO_SKU | 平台明确返回空 SKU 列表，不能推断为单规格 |
| MISSING | 平台未提供有效 SKU 列表字段 |
| BLOCKED | 账号熔断或平台访问受限；仅 USER_VALIDATE/CAPTCHA 明确提示人工验证 |
| FAILED | 其他详情获取失败 |

旧详情解析器兼容 `skuList` 与 `idleItemSkuList`，优先采用非空列表。`priceInCent` 仅接受非负且浏览器可精确表示的整数分；仅有未核对的 `price` 时标记 `UNIT_UNCONFIRMED`。当前竞品服务使用确认页解析器，读取 `skuInfoDetails` 完整组合中的 `skuPrice`，元转分规则有真实页面和分单位小计证据；不使用选项 `priceText` 推算组合价格。规格标准化参考 pilot-pro 的字段兼容方式，未沿用其未经核对的价格换算假设。

## 2026-10-07：更新 Cookie 后仍然 RGV587 的诊断

本地运行日志确认：用户手动更新完整 Cookie 会解除旧熔断，随后 `mtop.taobao.idle.pc.detail` v1.0 返回新的 RGV587，再开启 600 秒冷却。此前订单同步不是该次熔断的直接触发请求。普通 Set-Cookie 合并调用 `updateCookie`，不会清除熔断；只有完整凭证更新入口会清除。消息接口成功不代表详情接口已恢复。

用户确认同一个商品在常用 Chrome 能打开并显示规格价格。容器通过 RestTemplate 请求，未复用这个浏览器会话。账号、接口、Cookie 更新路径已定位，但浏览器成功请求的 api、v、ret 与 SKU 字段仍待对照；尚不能确定平台为何拒绝容器请求。

参考 [goofish-cli 商品详情](https://github.com/fancyboi999/goofish-cli/blob/main/src/goofish_cli/commands/item/get.py) 与 [mtop 调用](https://github.com/fancyboi999/goofish-cli/blob/main/src/goofish_cli/core/mtop.py)：接口名称、1.0 版本、itemId 参数、appKey 与签名模板基本一致，该项目也将 RGV587 作为风控异常停止处理。另两个参考项目使用浏览器采集；这些代码差异不是本次根因或可恢复性的证明。未改写浏览器指纹、绕过验证或关闭熔断。

修正：风控提示区分明确验证与一般拒绝，保留剩余冷却秒数；规格组件增加连接管理与官方商品页入口；一般 RGV587 的采集任务显示等待人工处理，继续固定重试上限并清空下次重试。新增安全事件日志只包含账号内部 ID、接口、版本及风控类别，不记录原始响应或凭证。

回归新增：RGV587 冷却阻断重复网络请求、收到 Set-Cookie 时仍保留限制且不刷新重试、一般拒绝任务停止自动重试、验证提示与一般拒绝区别、手机页面入口布局。16 个后端测试、2 个价格测试、10 个合成页面检查通过，类型检查、独立构建、UTF-8/换行检查、diff 检查通过。已查看桌面与手机限制提示截图。真实 SKU 采集仍未验收成功，不把提示修复称为采集恢复。
